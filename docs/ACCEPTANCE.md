## 6. 性能与内存（关键指标）

前置：`--demo-seed 5000 --yes` 造数（或手工压测），面板/管理台各进入一次后采样。

| 指标 | 目标 | 方法 |
|---|---|---|
| 空闲内存（隐藏） | ≤45MB WorkingSet | `tools\measure.ps1 -Samples 10` |
| 面板打开内存 | ≤60MB | 打开面板后 `tools\measure.ps1` |
| 冷启动到托盘 | ≤1.0s | 日志时间戳差 |
| 面板呼出 | ≤150ms | 多次测量取均值（日志） |
| 搜索响应（5000 条） | ≤100ms | `--diagnose`/自检 JSON 或日志耗时 |
| 列表滚动 | 60fps 不卡顿 | 人工观察 + 滚动录屏可选 |
| exe 体积 | ≤15MB | 文件属性 |
| 24h 内存 | 无持续上涨（≤+10MB） | 间隔采样（可缩短为 2h，记录） |
